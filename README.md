## 🚀 Flagship Architecture — AI Exam Authoring Harness

> **공공기관 AI 챔피언 시험 30세트 자동 출제 하네스** — 기관 첨부 자료만으로 90개 문제지·해설·채점 솔버·PDF·CBT JSON까지 완전 자동 생성 및 무결성 검증

```text
[Input] 기관 제공 첨부 자료 (보도자료 · 법령 · 통계 · CSV)
   │
   ▼
[Round 0] attachment-analyzer  →  자료 분류 & 콘텐츠 유형 식별
[Round 1] set-designer         →  30세트 × 3과목 주제 매핑
[Round 2] question-writer ×90  →  문항 5개 + 시나리오 (병렬 생성)
[Round 3] solve-writer   ×90   →  solve.py + 답안지 + 해설
[Round 4] leak-detector        →  정답 노출 8-pattern LLM 의미 검사 ↺
[Round 5] solve-verifier       →  solve.py ↔ 답안지 실행 정합성 검증 ↺
[Round 6] builder              →  응시자/채점자 PDF · ZIP · CBT JSON
   │
   ▼
[Output] 30세트 × 3과목 = 90 문제지 패키지 (Zero-Leak 검증 완료)
```

| 문항 자동 생성 | 그린(AI·엑셀) / 블루(Python·ML) 이중 트랙 |

| 실행 검증 루프 | `solve.py` 실구동 결과와 정답지 불일치 시 자동 라운드 복귀 |
| 보안 아키텍처 | 응시자·채점자 트리 완전 분리 (누출 0건 검증 필수) |
